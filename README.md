# Yara

Yara é uma aplicação desktop de criação visual construída com o [Vela Framework](https://github.com/zxlawdx/Vela-framework).

O projeto inclui uma tela inicial para gerenciar projetos e evoluirá para editores de esboços, interfaces e SVG.

O desenvolvimento é feito em branches de funcionalidade e revisado por Pull Requests.
